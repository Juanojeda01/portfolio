# 🚕 Taxi Fleet Performance Analysis

## Project Overview

This project analyzes one week of taxi fleet operations to evaluate
demand patterns, revenue concentration, driver efficiency, and
performance segmentation.

## Key Objectives

-   Identify peak operational days
-   Determine high-revenue time windows
-   Measure driver idle time
-   Detect underperforming drivers
-   Segment drivers using K-Means clustering

## Tech Stack

-   Python
-   Pandas
-   Matplotlib
-   Scikit-Learn
-   K-Means Clustering

## Business Impact

This project demonstrates how operational data can be transformed into
actionable performance insights to support data-driven fleet management
decisions.
